02 Research · Terrestrial LiDAR

One forest. Six methods. A common measure.

A comparison of six existing individual-tree segmentation methods. The challenge is making their predictions comparable, from point alignment to one-to-one tree matching.

The project

Project
Tree LiDAR benchmark
My contribution
Benchmark integration, aligned-label evaluation and reproducible result verification. Segmentation methods are credited to their original authors.
Tools & methods

Code & evidence ↗

The question

Individual-tree segmentation identifies separate trees inside a laser-scanned point cloud. Comparing methods requires more than running their code: predictions must refer to the same points and be judged under the same definition of a valid tree and a valid match.

The approach

  1. Integrate six third-party segmentation methods and evaluate their point-aligned predictions with one shared scoring protocol. The segmentation methods remain the work of their original authors.
  2. Match predicted and reference trees one to one, using the fixed protocol’s eligibility and overlap rules. Unmatched predictions and references contribute to the error counts.
  3. Keep published/default settings separate from configurations selected using development data. Preserve route identities and verify aggregate results against the retained per-plot records.

What came out of it

The benchmark provides a reproducible comparison with explicit matching rules, separate result routes and published verification code. It makes differences in the evaluation setup visible alongside the results.

Where the result stops

The methods received unequal development effort, so the two routes are not a controlled estimate of training benefit. The illustrated CULS plot was selected after scoring to show a clean match; it is not representative of every plot. Raw point clouds and prediction arrays are not distributed in the public portfolio.
