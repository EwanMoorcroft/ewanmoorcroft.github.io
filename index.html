01 3D computer vision · Evaluation

3D tree segmentation benchmark →

How can different tree-segmentation methods be compared under the same scoring rules? A common evaluation workflow for existing methods on UAV LiDAR point clouds.

My contribution. I integrated six third-party methods, evaluated point-aligned outputs and verified aggregate results. The original authors retain credit for the segmentation architectures.

Six methods compared across 11 held-out plots, 323 reference trees and 49.7 million points.

MSc dissertation · Python / Point clouds / Model evaluation

02 Applied ML · Temporal evaluation

FPL next-gameweek forecasting →

Forecasting Fantasy Premier League points using information available before the next gameweek, with chronological model comparisons and a local software interface.

My contribution. I implemented snapshot validation, as-of features, chronological evaluation, portable model artefacts and a read-only local API.

Ridge MAE: 1.110 points versus 1.130 for the three-observation mean baseline, across GW6–15 of 2024–25.

Independent project · Python / scikit-learn / DuckDB / Docker

03 Data science · Spatial statistics

Liverpool workplace-flow analysis →

How much recorded workplace movement stayed within Liverpool in Census 2021? An analysis of 61 statistical areas, with independent numerical checks in R.

My contribution. I rebuilt the workflow for data extraction, spatial analysis and statistical modelling, then independently checked numerical results in R.

84,567 of 123,689 included fixed-workplace flows remained within Liverpool: 68.37%.

Independent rebuild · Python / DuckDB / GeoPandas / R
